Auto-Schedule with Windows Task Scheduler
1
Open Task Scheduler

Press Win + S, search for Task Scheduler, open it.

2
Create Basic Task

Click Create Basic Task… on the right panel. Name it ToolTrack Backup.

3
Set the Trigger

Choose Daily (recommended) or Weekly. Set a time when the PC is on — e.g. 11 PM.

4
Set the Action → Start a Program

Program: C:\xampp\php\php.exe
Arguments: C:\xampp\htdocs\tooltrack\backup.php

5
Finish & Test

Click Finish. Right-click the task → Run to test it. Check your USB drive for the .sql file.

⚠
Always plug in the USB before the scheduled time

If the USB is unplugged, backup.php will log an error to backup_log.txt inside your project's /backups/ folder (local copy). Consider keeping the local copy as a fallback.
