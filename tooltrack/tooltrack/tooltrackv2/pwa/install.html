Open ToolTrack

Redmi Note 13

  1. Connect to the same Wi-Fi as the XAMPP computer.
  2. Transfer the ToolTrack local CA certificate from your server administrator. In Settings, search for Install a certificate and select CA certificate. Menu names vary between MIUI and HyperOS.
  3. Restart Chrome and open the server’s HTTPS address with no certificate warning.
  4. Use Chrome’s menu → Add to Home screen → Install (or Install app).

iPhone / iPad (Safari)

  1. Connect to the same Wi-Fi as the XAMPP computer and download the public ToolTrack CA certificate.
  2. Open Settings → General → VPN & Device Management and install the downloaded certificate profile.
  3. Open Settings → General → About → Certificate Trust Settings and enable full trust for FPST ToolTrack Local CA.
  4. Reopen Safari and open the HTTPS ToolTrack address without certificate warnings.
  5. Tap Share → Add to Home Screen. Enable Open as Web App if shown, then tap Add. Safari uses its Share menu rather than the Android install button.

Windows

  1. Trust the same local CA certificate in Current User → Trusted Root Certification Authorities. The setup script can do this for the server computer.
  2. Open the HTTPS address in Chrome or Edge.
  3. Click the address-bar install icon, or use the browser menu to install this site as an app.

The server must remain on. Student records, logins and transactions are not cached for offline use.
